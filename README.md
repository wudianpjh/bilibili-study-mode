# 📺 Bilibili Study Mode | B站学习模式

> **"Stay focused, Study hard."** > 这是一款专为处于复习阶段的学子打造的浏览器扩展，旨在将 B 站从“时间黑洞”转化为“学习利器”。

Ciallo～ (∠·ω· )⌒☆

## 🌟 为什么开发这个项目？

在准备考试的过程中，我发现 B 站虽然有丰富的学习资源，但首页的推荐和侧边栏的干扰项总是让人分心。希望在提升自己的同时也帮助到有同样困扰的同学。

------

## ✨ 核心功能

### 🏠 极简学习首页

- **沉浸式时钟**：实时显示当前时间与日期，时刻提醒考试倒计时。
- **纯净搜索**：保留核心搜索功能，直达学习资源，屏蔽首页诱惑推荐。
- **快捷入口**：一键跳转动态、收藏夹、历史记录，快速找到复习视频。

### 🛡️ 深度环境净化

- **屏蔽干扰项**：一键隐藏“赛事”、“创作中心”、“投稿”等与学习无关的按钮。
- **侧边栏瘦身**：可选隐藏番剧、直播、游戏中心等入口。
- **视频页聚焦**：自动隐藏视频右侧的推荐列表，防止点击“下一个”造成的时间浪费。

### 🖼️ 个性化体验

- **自定义壁纸**：支持 URL 或本地图片上传，将背景换成激励自己的话或喜欢的角色。
- **一键切换**：考试周全力冲刺，休息时随时还原原站首页。

## 🚀 安装教程

由于目前仅在 GitHub 发布，请按照以下步骤手动加载：

1. 点击本仓库右上角的 `Code` -> `Download ZIP` 并解压，或者使用 `git clone`。
2. 打开 Edge 或 Chrome 浏览器，进入 **扩展程序** 页面 (`edge://extensions` 或 `chrome://extensions`)。
3. 开启页面右上角的 **“开发者模式”**。
4. 点击 **“加载解压的扩展程序”**，选择你解压后的文件夹。
5. 在 B 站首页刷新，开启你的沉浸式复习之旅！

## 🛠️ 技术栈

- **Manifest V3** 标准开发。
- **原生 JavaScript** + **CSS3**，轻量化运行，不占用多余内存。
- **Chrome Storage API** 实现本地配置持久化。
